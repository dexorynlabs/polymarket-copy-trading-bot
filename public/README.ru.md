### История 3 - Бот работает после того, как Gabagool22 перестал быть целью

<a id="story-3--bot-still-running-after-gabagool22-stopped"></a>

Gabagool22 со временем **снизил активность и перестал быть практичной целью** - меньше сделок, другая модель или просто неактивность. Многие копи-трейдеры упираются в ту же стену: кошелёк, который работал в прошлом месяце, замолкает, и бот кажется «сломанным», хотя проблема в **отсутствии сигнала**, а не в софте.

Что мы сделали:

- Оставили **тот же бот** - без переписывания и «нового продукта»
- Обновили `target_wallet` в `config.yaml` на **другие активные кошельки Polymarket**
- Проверили весь пайплайн: детекция → размер позиции → ордер → логирование

Что увидели:

- ✅ Процесс стабилен
- ✅ Сделки новой цели детектируются и копируются корректно
- ✅ Логи и `state.json` обновляются как ожидается
- ✅ Сбои только в отдельных рыночных/ордерных кейсах, а не «бот умер вместе с Gabagool22»

## ⭐ Почему этот бот

### 🎯 Реальные доказательства, а не слова

У многих ботов Polymarket - только скриншоты. В репозитории - **видео live-исполнения** и истории выше.

### 🚀 Архитектура и производительность

- **WebSocket-поток сделок** - подписка на live activity Polymarket
- **Async-first** - Python `asyncio` с ограниченной очередью исполнений
- **Персистентное состояние** - дедуп и позиции в `state.json`

### 💡 Функции для трейдеров

- **Пакетирование shares** - накопление мелких сделок цели до порога
- **Fixed или percent sizing** - фиксированный USD или доля chunk
- **Dry-run** - `mode: dry_run` без реальных ордеров
- **Taker / Maker** - FAK или GTC
- **Лимит позиций** - `max_usd_total_in_positions`
- **Watchdog** - выход при «зомби» WebSocket

## 🎯 Кому подходит

**Подходит:**

- Трейдерам с **пассивным следованием** за доверенными кошельками
- Пользователям с **Python 3.10+** и `config.yaml`
- Тем, кто понимает **риски on-chain** и смену лидеров

**Не подходит:**

- Тем, кто ждёт **гарантированную** прибыль без контроля
- Новичкам, которые не смотрят логи и не меняют цели

### Требования

- **Python 3.10+**
- **Кошелёк Polygon** - USDC и gas (при `mode: real`)
- **Учётные данные Polymarket CLOB API** - для live-ордеров

### Установка

```bash

cd polymarket-copy-trading-bot

pip install -r requirements.txt

cp config.yaml.example config.yaml
# Отредактируйте config.yaml - target_wallet и mode (см. ниже)
python -m app.main
```

## Конфигурация

Отредактируйте `config.yaml` в корне проекта. Начните с `mode: dry_run`.

### Основные настройки

| Настройка | Описание | Пример |
|-----------|----------|--------|
| `target_wallet` | Кошелёк для копирования | `0x6031b6e...` |
| `mode` | `dry_run` или `real` | `dry_run` |
| `sizing.mode` | `fixed` или `percent_of_target` | `fixed` |
| `sizing.fixed_usd_per_fill` | USD за копию | `10.0` |
| `sizing.percent_of_target` | Доля chunk | `0.05` |
| `sizing.max_usd_total_in_positions` | Лимит открытых позиций | `100.0` |
| `sizing.min_target_shares_to_copy` | Порог пакетирования | `10` |
| `execution.order_type` | `taker` или `maker` | `taker` |
| `slippage.entry_bps_max` | Макс. slippage (bps) | `200` |

При `mode: real` заполните секцию `polymarket:` (`private_key`, `wallet_address`, `api_key`, `api_secret`, `passphrase`).

## Безопасность и риски

⚠️ **При `mode: real` бот совершает реальные сделки.**

- Начните с `mode: dry_run`
- **Меняйте `target_wallet`**, когда трейдер затих
- Ограничивайте `sizing.max_usd_total_in_positions`
- Смотрите `logs/tracecopy.log`; состояние в `state.json`
- Прошлые результаты **не гарантируют** будущее

1. Отдельный кошелёк с ограниченным балансом  
2. Не коммитьте `config.yaml` с секретами  
3. Уметь остановить бота (`Ctrl+C`)  
4. Изучать кошельки перед установкой `target_wallet`

## FAQ

**Можно ли ещё копировать Gabagool22?**  
Любой адрес можно указать, но Gabagool22 **не рекомендуется** - активность упала.

**Что если цель перестала торговать?**  
Бот продолжит работать; новых копий не будет, пока `target_wallet` не укажет на активный кошелёк.

**Работает ли на всех рынках Polymarket?**  
Стандартные рынки - да; экзотика может давать отдельные сбои.

**Это open source?**  
Да. Также есть premium-сборка с поддержкой в Telegram.
